# GULI 原生物理迁移与验证

日期：2026-10-19；Cocos Creator 3.8.8；浏览器预览使用项目现有的 Box2D JavaScript 后端。

2026-10-20 滚动手感调整：以下为迁移当日的历史配置与验证。最新参数、四档力度对比和关卡验证见 [滚动调校报告](rolling-tuning.md)。

## 修改前检查

- `settings/v2/packages/engine.json` 的 includeModules 已包含 `physics-2d-box2d`，无需安装另一个物理库。
- 旧 `GameModel.step()` 在 120 Hz 下自行更新坐标、每秒减速135、分离重叠并施加碰撞冲量。等质量冲量系数0.95对应约0.9的恢复系数；没有原生刚体。
- 安装的3.8.8源码确认：节点/碰撞半径采用像素；RigidBody2D.linearVelocity 使用 Box2D 米/秒；PTM=32。getWorldCenter 返回像素。
- 引擎默认自动步进、1/60秒、每帧最多1子步；速度/位置求解迭代各10；允许休眠。旧玩法没有使用这些默认值。
- 检查了 POST_SOLVE、刚体启停、CircleCollider2D 材质、质量计算和世界锁定规则。全局 POST_SOLVE 每个接触报告一次；不同时监听两个碰撞体重复施加效果。

## 迁移时配置（历史）

配置集中在 `assets/scripts/GuliPhysics.ts` 的 PHYSICS_CONFIG；发射范围和规则默认值在 `GameModel.ts`。

| 参数 | 实际值 |
| --- | --- |
| 固定步长 | 1/120 秒 |
| 每渲染帧最大子步 | 12；长帧最多接收0.1秒，模拟放慢而不跨大步 |
| 速度/位置迭代 | 10 / 10（保留引擎默认） |
| 恢复系数 | 0.45；实测0.3、0.45、0.6的碰撞公式 |
| 碰撞摩擦系数 | 0.05，仅作用于接触切向；没有额外手动摩擦 |
| 线性阻尼 | 0.65，由引擎执行一次 |
| 刚体重力倍率 | 0，平面俯视运动；不修改全局重力 |
| 质量 | 每颗1，包括发射球；密度按圆面积计算 |
| 目标球/发射球半径 | 30 / 32 像素 = 0.9375 / 1 米 |
| 场地半径 | 260 像素 = 8.125 米 |
| 发射速度 | 380 + clamp(p,0,1) × 820 像素/秒；11.875–37.5 米/秒 |
| 连续碰撞检测 | 所有弹珠 bullet=true；最多13颗 |
| 旋转 | fixedRotation=true，保持原先不模拟旋转的玩法 |
| 休眠 | allowSleep=true；回合确认静止后对留场刚体调用sleep |
| 静止条件 | 所有未出圈弹珠速度严格低于2像素/秒，连续0.25秒，期间无有效接触冲量 |

单位选择：2米/秒在此项目相当于64像素/秒，仍会明显移动。采用与原场地尺度一致的2像素/秒，即0.0625米/秒。默认阻尼下该阈值以下的无碰撞残余行程约3.1像素，小于球半径；确认静止后休眠。自动休眠仍保留，但不依赖瞬时速度判定。

## 步进、结算及保持不变的内容

使用同一个 `PhysicsSystem2D.instance`，autoSimulation=false，固定步长调用其原生step；没有保留旧积分器、重叠修正或碰撞冲量代码。手动调度用于沿用游戏暂停机制，并确保每个物理子步后处理边界和静止时间。

原生刚体挂在Scene根节点下，保持单位缩放，不跟随Canvas缩放或视觉纵向0.87压缩。物理节点不渲染，也不会从界面坐标回写位置；每步通过原生getWorldCenter和linearVelocity读取结果，再由原来的显示逻辑映射到画面。这样不需要反复同步视觉变换导致刚体瞬移。以后若需要传送物理球，应明确同步原生刚体，而不是只移动显示节点。

每次step返回后，全部碰撞回调已经完成，再检查 `distance > R + r`。等于边界不算出圈。出圈球先标记并在世界解锁后禁用刚体；所有相关弹珠连续静止后才累计击出数量、移除发射球、判定胜负/剩余次数。发射球保留原有圈外出生豁免、入场后出界和远离场地清理规则。取消旧的15秒强制结束，避免仍有碰撞时误结算。

界面、素材、关卡布局、次数、三星门槛、收藏ID、存档规则均保持。目标计数现在在回合结束统一提交，符合本次结算要求。物理手感由新恢复系数和阻尼决定，不保证逐帧复制旧模拟轨迹。

暂停不调用step；继续后只累计新模拟时间。重玩、离开、销毁时禁用并清理旧刚体和监听，恢复之前的引擎设置。此适配器拥有当前场景物理步进；若未来加入另一个玩法的物理控制器，应统一步进所有权。

## 实际运行的验证

- `npm.cmd test`：10项规则测试通过；这组测试不伪装成物理模拟测试。
- `npm.cmd run typecheck`：通过。
- Cocos浏览器预览 `http://localhost:7456/?guliPhysicsTest=1`：11组真实引擎测试通过，0失败，完整原始结果在 `physics-test-results.txt`，截图在 `physics-tests.png`。
- 覆盖：单位/质量、0.3/0.45/0.6恢复系数的解析速度和动量、不同质量、能量不增加、无重复冲量、单次阻尼、完整出圈/延迟计数、连续静止/取消超时、暂停/恢复/重玩、重叠分离、高速防穿透、30/60/144 FPS与长帧、最后一发胜出、五关三星路线。
- 首轮边界用例失败是测试只移动了不参与场景同步的节点；改为通过原生速度越过边界后重新运行全套并通过。没有改松边界公式。
- 正常游戏界面实际操作：进入第一关、点击发射、运动中按Esc暂停、点击继续、等第一发结算、重新瞄准并第二次发射，得到2发击出2颗的三星胜利画面；浏览器捕获的错误/警告日志为空。截图见 `physics-gameplay.png`。此正常试玩按原规则保存了本次奖励；独立自动测试入口不接触存档。
