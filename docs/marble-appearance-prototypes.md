# 弹珠外观：第二阶段原型

日期：2026-10-21。仅为既有 ID 10、33、45 增加视觉覆盖；其余 47 颗保留原绘制。没有新增可收藏 ID，也没有改变名称、稀有度、存档格式、装备规则或物理参数。

## 配置和实现

| 原 ID | 原名称 / 稀有度 | 本次外观 |
| --- | --- | --- |
| 10 | 海蓝涟漪 / 普通 | 蓝色玻璃、三层椭圆波纹、内部弧形蓝带 |
| 33 | 紫晶花瓣 / 稀有 | 紫色珍珠玻璃、五瓣半透明花、浅金花心、下缘珠光 |
| 45 | 月白幻彩 / 珍藏 | 青蓝虹彩玻璃、双色弧带、奶白兔子轮廓与三处星光 |

界面编号仍为 ID+1，因此显示 #11、#34、#46，不是改了 ID。

`MarbleAppearance.ts` 只保存视觉配置。`MarbleRenderer.ts` 共用绘制逻辑：球体和阴影、内部纹路和主题、最上层高光和边缘光。内部节点使用 Cocos `Mask.Type.GRAPHICS_ELLIPSE`，48 段，半径为球半径的 0.9 倍。半透明叠色与覆盖高光模拟玻璃层次，不是真实折射。

`GuliGame.ts` 保留 `marble()` 与所有调用位置，仅给这三个 ID 转发新渲染器。ID -2 的未发现占位、ID 0 的发射球及其他 ID 继续执行原代码。主页中的 ID 33 也使用同样外观。无新增 Shader、自定义材质、贴图、动画或每帧图形重建。

## 复现与限制

打开 Guli 场景，预览地址增加 `?guliMarblePreview=game`，或 `?guliMarblePreview=10`、`33`、`45`。`MarbleAppearancePreview.ts` 仅通过显式预览参数运行，使用内存中的三颗收藏与固定展示布局，同时禁止该预览实例保存。移除参数刷新即恢复正常数据。它不代表玩家已经获得这些弹珠。

每颗原型使用 3 个 Graphics 与 1 个圆形 Mask；遮罩会增加模板缓冲绘制及批次切换。没有测得真机帧率、GPU 时间或 draw call 数量，不能声称性能提升或 Huawei RPK 已兼容。正式扩展前应在目标手机上检查最多 13 颗场内弹珠及 10 颗收藏展示的开销。

尚未扩展其余 47 颗、未做手机/RPK 真机验证。原型供审阅后决定是否继续第三阶段。
