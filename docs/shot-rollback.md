# 边界接触有效、平滑回滚与次数反馈

2026-10-22。替代 2026-10-21 的“玩家整颗出圈才有效”规则。

## 当前行为

- 每次接受发射时保存目标对象引用及全部字段、既有击出进度，并仅在 `launch()` 扣一次次数。
- 玩家弹珠以每个物理步前后位置形成的线段，检测扫过的圆盘是否接触圆圈线。接触状态锁存，弹回圈内仍有效。从圈外进入时第一次接触也有效；仅在圈外出生不算接触。
- 接触容差为 0.0001 地面像素；目标完整出圈仍严格使用 `distance > 260 + target.r`，相切或部分出圈不计入。
- 沿用 2 地面像素/秒、连续 0.25 秒、无有效碰撞冲量的停止判定。运动中的出圈记录暂存；已完整离圈并停止参与碰撞的球无需继续等待。
- 有效发射保留所有碰撞结果，包含零目标出圈的发射。
- 无效发射进入独立 `rollback` 阶段，禁止发射。目标及发射球沿三次缓出曲线在 0.4 秒内恢复。发射球回到现有拖拉起点 `(0,-350)`，不是拉满后的松手位置。
- 次数文字立即变红，0.13 秒内放大至原比例的 1.3 倍，随后恢复。总时长 0.5 秒；保存并恢复实际颜色和比例，不假定白色或单位缩放。
- HUD 和回滚共用现有 update 时钟，暂停时同步停止。refreshHud 只更新文字，不重启动画。优先作用于 ShotsPlate 的 Label，缺少素材时作用于合并 HUD。
- 0.5 秒完成后原位恢复原目标对象、进度和物理状态。完整出圈的目标刚体只暂时停用，回滚复用原节点及碰撞体。通过引擎 `physicsWorld.syncSceneToPhysics()` 同步恢复的位置，并清零刚体速度、休眠。
- 回滚完成后才决定继续、胜利或失败。目标达成优先于次数耗尽；不会退款或再次扣次。
- 切页、重玩、销毁节点前恢复 HUD 属性并清理动画引用。正常回滚不重建弹珠或关卡。

未改速度范围 380–1600、阻尼 1.6、恢复系数 0.25、摩擦系数 0.05、质量 1、1/120 秒物理步，以及瞄准、力度、关卡、弹珠 ID、收藏和存档格式。

## 实际验证

- `npm.cmd test`：17 项模型、6 项 Slingshot、3 项瞄准预测，共 26 项通过。
- `npm.cmd run typecheck`：通过。
- Cocos 3.8.8 真实 Box2D 预览 `?guliRollbackTest=1`：6 组通过。覆盖普通/最后一次有效与无效发射、有效零击出、暂时移除目标的同对象/同碰撞体恢复、下一次发射无旧速度漂移。移除目标恢复用显式碰撞后位置夹具，不声称该位置由自然碰撞生成。
- 真实场景 `?guliRollbackUiTest=1`：5 组通过。覆盖平滑返回、最新次数、红色与 1.3 倍缩放、精确恢复、refreshHud 连续更新、输入锁、最后一次延后失败、非默认颜色/缩放、后备 HUD、重触发清理、切页、取消拖拉、有效射击不提示、暂停/继续、重玩。
- `?guliSlingTest=1`：4 组现有鼠标/触控事件及实际物理回归通过。
- 规则快照测试包含边界接触后弹回、跨物理步穿越边界、目标相切不出圈、进度恢复、胜利优先、存档清洗和收藏奖励。弹回边界测试为规则夹具，不是自然碰撞路线演示。
- 实际预览检查并保存 HUD 动画峰值画面：`invalid-shot-hud.png`。截图使用显式预览测试参数，暂停在动画 0.13 秒；正常游戏不会冻结。
- 实测曾发现恢复后的物理中心未同步，补充引擎位置同步后全部重跑通过。

## 文件

- `assets/scripts/GameModel.ts`：接触锁存、稳定对象快照、回滚阶段与缓动、延后结算。
- `assets/scripts/GuliPhysics.ts`：暂存出圈刚体、回滚暂停物理、恢复同步及清理。
- `assets/scripts/GuliGame.ts`：HUD 动画、回滚显示、输入锁衔接、保留返回的发射球视觉、预览入口。
- `assets/scripts/RollbackVerification.ts`、`tests/game-model.cjs`：相应验证。
- 本文及截图：验证记录。

## 限制

未验证原生移动端构建、真实手机触屏、五关完整通关路线和跨重启存档流程。浏览器触控验证使用 Cocos 触控事件，不等同手机真机测试。既有完整通关路线记录不能自动视为本规则的验证结果。
