# 弹弓发射操作

2026-10-20：在现有游戏中替换瞄准、力度滑块及发射按钮。保留现有弹珠外观、HUD 素材、关卡、收藏、失败回退和 Box2D 物理。底部力度面板略微下移，为向后拖拉留出空间。

## 操作与参数

- 从自己的弹珠开始按住；球跟随鼠标或拥有该次拖拉的手指。偏离球心按下不会让球突然跳动。
- 最大拖拉距离为 120 个 Canvas 设计像素，球的位移和力度同时封顶。设计分辨率仍为 720 × 1280。
- 起点周围 8 个设计像素为取消区。未离开取消区松手不会射击；离开后力度为 1–100，64 像素对应 51，120 像素对应 100。
- 力度条仅显示实时力度，不再单独拖动。力度 1 对应最低速度 380，力度 100 对应最高速度 1600，单位为地面像素/秒。2026-10-20 提高阻尼后扩大高速端，保留高力度的过关能力。
- 松手从拖拉后的球位发射，方向与拉动相反。纵向坐标使用现有 0.87 投影比例换算，瞄准线与发射方向一致。
- 瞄准器为虚线加箭头，按当前速度和线性阻尼估算未来 0.8 秒的直线距离。使用弹珠实际半径进行扫掠检测，在首个弹珠接触位置或圆圈出口截断；不预测碰撞后的反弹。
- 圆圈不是物理墙：预览允许发射球从圈外进入，在球前缘到达远端圈线时停止。真实出圈判定仍为整颗弹珠离圈。箭头端点表示预计球心位置，不表示两球表面的接触点。
- 拉回起点后松手、Esc、鼠标右键、系统 TOUCH_CANCEL、切换后台或浏览器失焦均取消；不消耗次数。
- 只接受最先抓住弹珠的手指。忽略第二根手指；触控后 600ms 内忽略合成鼠标事件，避免重复发射。
- 拖拉时只有展示球移动；松手才创建原有物理刚体。继续使用现有碰撞、阻尼、出圈、静止与回合结算逻辑。

## 手动验收步骤

1. 打开 Guli 场景预览，进入第一关。按住下方自己的弹珠，慢慢向后拉，确认球跟随、力度数值与条同步增长，瞄准线指向反方向。
2. 拉到上限，再继续拉远，确认显示 100 且球位不继续远离起点。试试左下、右下拉动。
3. 松手，确认立即发射且只减少一次机会；弹珠滚动中不能开始新发射，静止后可再次拖拉。
4. 分别测试轻点、拉回起点松手、Esc、右键取消。确认球归位且机会不变。再测试拖拉时切换窗口。
5. 手机触屏预览中重复上述拖拉与松手；加上第二根手指，确认第二根不会改变方向或触发发射。拖拉时切到后台再回来，确认归位且不扣次数。
6. 原生移动端构建后在真机复测：不同屏幕比例、手指离开游戏区域、系统触控取消、后台恢复、连续快速拖拉、关卡失败重玩、成功收藏与最后一次射击获胜。

原生移动端发布包尚未构建或真机验证，不能据此确认平台兼容性。生产输入使用 Cocos 统一触控 API；浏览器失焦监听有平台判断，不作为手机端的必要依赖。
