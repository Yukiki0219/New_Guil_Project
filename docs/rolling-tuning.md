# 滚动手感调校

2026-10-20，Cocos Creator 3.8.8，项目实际 Box2D 浏览器预览。

## 原因与修改

顶视游戏使用零重力倍率，没有与地面持续接触的碰撞体。碰撞摩擦 0.05 只在球间接触时作用，不会让独立滚动的球持续减速。原线性阻尼 0.65 产生较长的低速拖尾。POST_SOLVE 只报告碰撞，未发现重复施加冲量。

| 参数 | 修改前 | 最终值 |
| --- | --- | --- |
| 线性阻尼 | 0.65 | 1.6 |
| 恢复系数 | 0.45 | 0.25 |
| 接触摩擦 | 0.05 | 0.05 |
| 最低/最高初速，地面像素/秒 | 380 / 1200 | 380 / 1600 |
| 质量 | 1 | 1 |
| 停止速度/连续时长 | 2 像素/秒 / 0.25 秒 | 不变 |
| 固定步长、求解器迭代 | 120 Hz、10/10 | 不变 |

只使用引擎线性阻尼，不增加手动摩擦、速度截断或碰撞冲量。引擎每步平滑衰减速度；低初速更早进入连续低速确认区。仍须全部留场弹珠低于阈值且没有有效碰撞持续 0.25 秒才能结算。休眠、连续碰撞检测、出圈与奖励规则保留。

最初仅提高阻尼、降低恢复系数时，实际 Slingshot 起射位置下的第三关未找到可完成路线。将最高速度扩大到 1600 后五关均完成。1–100 力度、拖拉距离及线性插值方式不变，未缩小力度差距。瞄准预测读取相同速度常量与实际阻尼，自动同步。

## 实测对比

采用真实刚体和碰撞体；同一测试依次运行旧参数及最终参数。仅在独立测量夹具中关闭出圈移除，避免把“离圈删除”当成“停止”。下表不是游戏场内的可视行程。单位为地面像素、模拟秒。双球间初始球心距离 90，四球测试后续间隔 65。

| 力度 | 单球距离，前 / 后 | 单球停止秒数，前 / 后 | 双球被撞球距离，前 / 后 | 四球链最大目标位移，前 / 后 |
| --- | --- | --- | --- | --- |
| 10% | 696.69 / 305.98 | 8.63 / 3.72 | 483.76 / 173.18 | 246.25 / 72.31 |
| 30% | 951.54 / 460.03 | 9.10 / 3.97 | 668.54 / 269.46 | 343.75 / 112.39 |
| 50% | 1206.40 / 614.06 | 9.47 / 4.15 | 853.31 / 365.74 | 440.51 / 151.68 |
| 100% | 1843.55 / 999.16 | 10.13 / 4.46 | 1315.23 / 606.43 | 683.30 / 248.98 |

四档力度均保持行程递增。双球整组停止时间为 3.42 / 3.67 / 3.86 / 4.17 秒；四球链为 2.84 / 3.11 / 3.32 / 3.59 秒。未见能量增加、穿透或结算时仍高于停止阈值。

降低恢复系数减少同等入射速度下的反弹和速度传递；提高最高初速后，高力度的瞬时目标速度不保证比旧版更低。例如 100% 双球测试目标峰速从 856.01 增至 961.04 像素/秒，但最终目标行程减少约 54%。这是保留高力度击球能力的取舍，不应宣称所有碰撞峰值均降低。

## 回归结果

- `npm.cmd test`：19 项逻辑测试通过。
- `npm.cmd run typecheck`：通过。
- `?guliPhysicsTest=1`：12 组真实引擎测试通过，包括四档力度的单球、双球、四球链共 12 种前后对比。
- 其他引擎检查：质量和单位、恢复系数 0.25/0.3/0.45/0.6、无重复冲量、停止持续时间、暂停恢复、重叠分离、最高速度防穿透、30/60/144 FPS、最后一发获胜、完整出圈后计数。
- 实际 Slingshot 起射位置下五关分别使用 2 / 2 / 5 / 4 / 4 次，获得 3 / 3 / 2 / 3 / 3 星。第三关三星路线未验证，旧路线不保证适用。未修改关卡、星级门槛或机会次数。
- 手机及 Huawei RPK 真机未测试；以上为浏览器中的真实引擎自动验证，不替代主观手感试玩。
